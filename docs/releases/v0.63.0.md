## Summary

This release fixes how the camper's faces are drawn and tidies up internals. Open `yasuflatland-ride-0.63.0.mcaddon` on a device to import both packs.

### Fixes

- The camper's east and west faces are now placed correctly, so ribs and hardware face outward.

### Before you update

- Restart the server after installing so the new Resource Pack version loads.

### Requirements

- Minecraft Bedrock Edition 1.21.120 or later
