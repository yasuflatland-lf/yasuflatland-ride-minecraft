## Summary

This release adds exhaust smoke to the scooter and a two-level shape menu to the building tools, and makes the scooter riders lean into turns. Open `yasuflatland-ride-0.57.0.mcaddon` on a device to import both packs.

### What you can do

- **See the scooter exhaust.** The scooter puffs smoke from its tailpipe, and the amount changes with its speed.
- **Watch the riders lean.** The scooter driver and passenger lean into turns while riding.
- **Pick build shapes from two menu levels.** The build menu now groups its entries, so edit actions and shape builds are easier to find.

### Fixes

- The paste menu no longer offers Undo; use the Build Undo item instead.
- The scooter model is lighter after removing hidden tyre details.

### Before you update

- Restart the server after installing so the new Resource Pack version loads.

### Requirements

- Minecraft Bedrock Edition 1.21.120 or later
