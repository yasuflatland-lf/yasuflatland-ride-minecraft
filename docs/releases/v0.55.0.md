## Summary

This release adds the Paste Rotate, Paste Place and Build Undo items for the Build Wand, gives the scooter a Vespa engine sound and telescoping flight struts, and fixes paste control taps on iPad. Open `yasuflatland-ride-0.55.0.mcaddon` on a device to import both packs.

### What you can do

- **Control a paste with items.** The new Paste Rotate and Paste Place items turn a pending Build Wand paste by hand and place it without sneaking. The action bar shows the current paste rotation.
- **Undo a build.** The new Build Undo item reverts your last Build Wand edit. Build mode stays on while you hold it.
- **Hear the scooter.** The scooter now plays a Vespa-style engine sound.
- **Fly the scooter with struts.** In flight the scooter extends front and rear telescoping struts under its fork and cowl, and its headlights stay lit.

### Fixes

- Short block taps on the paste control items now work on iPad.
- The control item icons are redrawn as black glyphs on yellow so they are easier to read.

### Before you update

- Restart the server after installing so the new Resource Pack version loads.

### Requirements

- Minecraft Bedrock Edition 1.21.120 or later
