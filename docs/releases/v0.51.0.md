## Summary

The camping gear gets a visual upgrade: ten items are redrawn with finer shapes and painted textures. Open `yasuflatland-ride-0.51.0.mcaddon` on a device to import both packs.

### What you can do

- **See sharper camping gear.** The cactus pot, macrame planter, potted plant, transistor radio, saucepan, mug pair, enamel kettle, sugar pot, toaster, and percolator now have rounder shapes, painted details, and more realistic proportions. Gameplay is unchanged.

### Before you update

- Restart the server after installing so the new Resource Pack version loads.

### Requirements

- Minecraft Bedrock Edition 1.21.120 or later
