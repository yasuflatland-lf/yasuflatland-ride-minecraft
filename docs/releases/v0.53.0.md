## Summary

The camper's kitchen now has working drawers, and its interior looks more finished. Open `yasuflatland-ride-0.53.0.mcaddon` on a device to import both packs.

### What you can do

- **Open the camper's kitchen drawers.** The two kitchen drawers slide open when you press them, and you can store camping gear in them.
- **Enjoy a refreshed camper interior.** The walls, floor, curtains, fridge, shower room, seats, dashboard, and steering wheel have new, more detailed looks.
- **Find build shapes faster.** The build shape menu now lists Cut, Remove above, and Rotate first.

### Fixes

- The SUV's rear arch panel is raised, so spinning rear tires no longer poke through it.
- The camper's fridge front no longer shows visual artifacts.

### Before you update

- Restart the server after installing so the new Resource Pack version loads.
- The camper can no longer be repainted.

### Requirements

- Minecraft Bedrock Edition 1.21.120 or later
