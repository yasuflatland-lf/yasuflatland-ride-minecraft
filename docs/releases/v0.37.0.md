## Summary

This release replaces the Build Tool with the Build Wand, a single wand that builds lines, rectangles, boxes, and roofs with a live preview, and adds round hover glows under the camper. Open `yasuflatland-ride-0.37.0.mcaddon` on a device to import both packs.

### What you can do

- **Build with the Build Wand.** Tap blocks with the wand to set points, then pick a shape (line, rectangle, or box, solid or hollow) or a roof (gable or hip, solid or hollow) from the menu. You can also tap the air to aim, and paste a saved build where you look.
- **See the result before you build.** Markers and outlines show the shape, roof, or paste while you choose.
- **No bulldozer needed.** Building no longer requires a bulldozer.
- **See round hover glows under the camper.** The camper's wheels glow in flight like the SUV's, and the glow stays bright under shaders.

### Before you update

- The Build Tool is gone; use the Build Wand instead.
- Restart the server after installing so the new Resource Pack version loads.

### Requirements

- Minecraft Bedrock Edition 1.21.120 or later
