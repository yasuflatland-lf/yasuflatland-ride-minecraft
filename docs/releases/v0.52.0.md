## Summary

Three new camping gear items join the collection: a twin-bell alarm clock, an instant camera, and binoculars. Open `yasuflatland-ride-0.52.0.mcaddon` on a device to import both packs.

### What you can do

- **Place new camping gear.** The twin-bell alarm clock, instant camera, and binoculars can now be placed in your camp. Each has a finely modeled shape with painted details.

### Before you update

- Restart the server after installing so the new Resource Pack version loads.

### Requirements

- Minecraft Bedrock Edition 1.21.120 or later
