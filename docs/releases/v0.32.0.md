## Summary

This release gives the camper a ribbed, glossy ivory body with aluminium roof rails, a roof edge with bolt heads, and framed doors and windows. Open `yasuflatland-ride-0.32.0.mcaddon` on a device to import both packs.

### What you can do

- **See the camper's new body.** The side walls and door are ribbed in a glossy ivory panel pattern.
- **See the camper's roof hardware.** Aluminium roof rails with posts run along the roof, and the roof edge carries bolt heads.
- **See the framed doors and windows.** The door is framed in aluminium and the windows in grey-beige trim, with hardware at the door latch.

### Before you update

- Restart the server after installing so the new Resource Pack version loads.

### Requirements

- Minecraft Bedrock Edition 1.21.120 or later
