## Summary

This release makes the Build Wand's start and end markers easier to see and makes warp landings more forgiving. Open `yasuflatland-ride-0.61.0.mcaddon` on a device to import both packs.

### What you can do

- **See your endpoints clearly.** The start and end markers are denser cubes with their own colors: white for the start, red for the end, and orange when both are the same cell. The start stays visible while you aim the end, and tapping one cell twice shows a single shared marker.
- **Land more reliably after a warp.** The warp block now picks the nearest standable cell within a 5x5 area instead of a few fixed spots, so a blocked spot next to the block no longer sends you to the top.

### Before you update

- Restart the server after installing so the new Resource Pack version loads.

### Requirements

- Minecraft Bedrock Edition 1.21.120 or later
