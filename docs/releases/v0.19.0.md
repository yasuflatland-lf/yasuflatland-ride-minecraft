## Summary

This release lets the bulldozer and the camper be placed in the same space as the SUV. Open `yasuflatland-ride-0.19.0.mcaddon` on a device to import both the Behavior Pack and the Resource Pack.

### What you can do

- **Place the bulldozer in tight spots.** It now needs the same 3 x 3 blocks of room as the SUV, so you can put it down on a rock or in a narrow gap that used to refuse it.
- **Place the camper in tight spots.** It also needs the SUV's 3 x 3 blocks, instead of a 9 x 9 square. Its long body can reach past that room, so its front or back may sit inside a nearby wall until you drive away from it.

### Before you update

- Restart the server after installing, because the pack versions changed.

### Requirements

- Minecraft Bedrock Edition 1.21.80 or later
- Developed and tested on a Bedrock Dedicated Server on a home LAN
