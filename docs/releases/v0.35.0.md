## Summary

This release refines the SUV's driver view: a thinner windshield frame that sits level with the hood, and a round, glossy black steering hub. Open `yasuflatland-ride-0.35.0.mcaddon` on a device to import both packs.

### What you can do

- **See more of the hood from the driver's seat.** The dark frame along the bottom of the windshield is now a thin rail level with the hood, instead of a tall band across the view.
- **See a round, glossy steering hub.** The centre of the steering wheel is now a black disc with a soft shine, instead of a dark star-shaped block.

### Before you update

- Restart the server after installing so the new Resource Pack version loads.

### Requirements

- Minecraft Bedrock Edition 1.21.120 or later
