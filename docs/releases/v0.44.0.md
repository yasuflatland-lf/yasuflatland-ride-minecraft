## Summary

This release has no new features. It tidies the code behind the vehicles, camping gear, and roof tent so that future updates are safer to make. Driving and building work as in 0.43.0. Open `yasuflatland-ride-0.44.0.mcaddon` on a device to import both packs.

### Before you update

- Restart the server after installing so the new Resource Pack version loads.

### Requirements

- Minecraft Bedrock Edition 1.21.120 or later
