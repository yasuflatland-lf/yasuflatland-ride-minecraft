## Summary

This release adds the Booster, a creative-only item that switches flight boost on and off for flying vehicles. Open `yasuflatland-ride-0.65.0.mcaddon` on a device to import both packs.

### What you can do

- **Boost your flight.** Hold the Booster as the driver of a transforming or flying vehicle to switch flight boost on or off. The Booster is available from the creative inventory.
- **Clearer switch messages.** The Headlight Switch and the Booster now report their on and off state the same way.

### Fixes

- The SUV's round headlight lens now lights up in its own lamp colours when the headlights are on.
- A boosted touchdown no longer jolts the vehicle, and the boost is released when the last driver leaves.
- Persona previews no longer log a Molang error about the spear variable.

### Before you update

- Restart the server after installing so the new Resource Pack version loads.

### Requirements

- Minecraft Bedrock Edition 1.21.120 or later
