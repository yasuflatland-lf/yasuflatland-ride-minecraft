## Summary

This release makes the Build Wand easier to aim on touch devices: pasting and the Stairs and Terrace goal now follow the block you tap instead of the camera. Open `yasuflatland-ride-0.67.0.mcaddon` on a device to import both packs.

### What you can do

- **Tap to place a paste.** Tap a block to set where the copy goes, tap another block to move it, and tap the same block again (or press Paste Place) to paste. Turning the camera no longer moves the box. The paste facing is fixed at the first tap, and after a paste you stay ready to paste again.
- **Know where a paste lands.** A pasted box is anchored at the corner where you started the copy, and the paste preview marks that corner with a white cube, like selection point 1.
- **Tap to set the Stairs and Terrace goal.** Tap a block to set the goal, tap another block to move it, and tap the same block again to open the contents menu. Turning the camera no longer changes the goal or the stair preview.
- **Fill in one step.** Fill is now at the top level of the Build Wand menu. The menu that opens right after you confirm a selection starts with Fill; later opens for the same selection start with Edit height again.

### Fixes

- The Build Wand's start and end markers are larger and stay bright at night.

### Before you update

- Restart the server after installing so the new Resource Pack version loads.

### Requirements

- Minecraft Bedrock Edition 1.21.120 or later
