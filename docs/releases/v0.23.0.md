## Summary

This release rebuilds the sports boat's wake-tower roof from a few large flat panels, so the soft top no longer shows stair steps. Open `yasuflatland-ride-0.23.0.mcaddon` on a device to import both packs.

### What you can do

- **See a smoother sports boat roof.** The bimini top is now three long panels with one darker zip hatch, domed gently with a rolled front lip, instead of many thin slices.
- **Notice the new side skirts.** The roof's sides drop away outward as single sloping sheets, and the rear corners step down more steeply.

### Before you update

- Restart the server after installing so the new Resource Pack version loads.

### Requirements

- Minecraft Bedrock Edition 1.21.120 or later
