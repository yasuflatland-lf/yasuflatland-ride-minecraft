## Summary

This release fixes the Build Wand roof flow, so a gable or hip roof can now be built from start to finish. Open `yasuflatland-ride-0.38.0.mcaddon` on a device to import both packs.

### Fixes

- **Build roofs with the Build Wand.** After you choose Gable roof or Hip roof, tapping a block or long pressing in the air now confirms the height you are aiming at and opens the Fill/Hollow menu. Before, these taps did nothing and the roof could not be built.

### Before you update

- On the iPad, a short tap on air sends nothing to the game. Use a long press of about one second for every air action with the Build Wand: an end point in the air, confirming a roof height while looking at the sky, and the utility menu. Tapping a block works as usual.
- Restart the server after installing so the new Resource Pack version loads.

### Requirements

- Minecraft Bedrock Edition 1.21.120 or later
