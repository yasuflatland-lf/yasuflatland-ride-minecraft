## Summary

This release adds the Noga Chair to the camping gear. Open `yasuflatland-ride-0.26.0.mcaddon` on a device to import both packs.

### What you can do

- **Sit in a Noga Chair.** Craft the Noga Chair and place it at camp. Its seat sags into a reclined back on an X frame, so it folds flat and stands up like the other camp chairs.

### Before you update

- Restart the server after installing so the new Resource Pack version loads.

### Requirements

- Minecraft Bedrock Edition 1.21.120 or later
