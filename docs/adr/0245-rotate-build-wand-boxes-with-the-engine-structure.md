## Context

The owner copies a furnished building (containers, signs, beds, doors, stairs, furnaces) and wants the copy turned to another heading, and also wants to turn an already selected building in place. A rotation that drops or mis-orients any block is not acceptable. The design has the full intent, goals and open risks.

Since 0243 the clipboard is an engine structure, so the engine can rotate it. Hand-written facing, direction, axis and hinge tables in the domain layer would be large, fragile and would drift from the engine.

## Decision

1. Rotation is horizontal quarter turns only, clockwise seen from above, 90 degrees per step.
2. The rotation is done by `StructurePlaceOptions.rotation` in the structure store. The code never contains block-state rotation tables.
3. `BuildStructureStore.place` accepts a quarter-turn rotation argument. The internal paste turn and `RotatePasteAim` remain available to test hooks, with odd turns swapping the X and Z footprint sizes at the same minimum corner. The player-facing Paste menu offers no Rotate; rotation is entered from a selected box as described below.
4. Phase 2 rotates a selected box in place about its center, from a Rotate entry after Copy and before Cancel in the endpoint shape menu. Horizontal rectangles use the same height step as Cut and Copy; other selections rotate immediately. The new box has size (sz, sy, sx). Cells of the new box outside the old box are overwritten, including terrain, water and neighbors. The operation is refused with a message and no change only when a cell of the union of the old and new boxes fails `mayEdit`, or when max(sx, sz) exceeds 64 or the max(sx, sz) by max(sx, sz) footprint times the height exceeds `BUILD_SPEC.maxCopyVolume`. The undo snapshot covers the union box, so Undo restores the overwritten cells. The order is: capture the snapshot, capture the source, clear the old box, place rotated, record the snapshot; any failure restores the snapshot. Success enters rotate mode with the rotated box, dimension and material at turn 1. Each plain item-use tap rotates real blocks one more quarter turn and adds one snapshot to the shared history. Sneak plus press finishes without writing and leaves the last box as the endpoint selection. The mode line shows accumulated degrees (90, 180, 270, 0) and both gestures on each outline interval, with the existing sneak indicator. Block interaction only cancels; item use handles block, air and missing aim without opening menus. A 7-tick rotate debounce exceeds held repeats every 4-6 ticks (0024) while admitting taps below the common 10-tick window; every attempt updates both the rotate and ordinary windows so held repeats after finish cannot open utilities. Disconnect, death, dimension change and leaving the wand end the mode with blocks as last rotated. History survives death, dimension change and item switch, but is discarded on disconnect. Undo is chosen from utilities after finishing.
5. Center rule: `newMin.x = oldMin.x + trunc((sx - sz) / 2)` and `newMin.z = oldMin.z + trunc((sz - sx) / 2)`, where trunc rounds the half-cell offset toward zero; Y is unchanged. A turn swaps the sizes, so the offsets of two consecutive turns are exact negatives of each other: two turns, and therefore four, return the box exactly, with no drift. A property test asserts that applying the rotation twice returns the original box. Negative zero is normalized. The height-step limit and `rotateTooLarge` both measure the union of the old and new boxes.
6. Mirror, flip, stacking, vertical (sideways) turns and 45 degree turns stay out. A pasted region is not selected by paste; to rotate a pasted building the player selects it with two points.

## Consequences

- Rotation snapshots share the per-player `BUILD_SPEC.undoDepth` (10) entry history with paste, cut and cell edits, as in 0243. Evict the oldest entry first and discard its structure handle when it is a snapshot.
- Entities with a `yasu_ride:` or `yasu_build:` identifier are excluded from structures and are not moved, as in 0243. Item frames, paintings and mobs follow whatever the structure keeps today; if the probe shows they are lost or mis-turned, that is recorded as a limitation.
- Phase 2 overwrites blocks outside the old box by design. This is acceptable only because the undo snapshot covers the union box.
- Revisit if the engine raises or changes the structure size limit, if placement over existing blocks does not write air, or if device checks require tuning the rotate debounce. Rotate mode provides repeated selected-box turns without reopening a menu; clipboard rotation remains absent from the paste menu.

`build_rotate_box` covers in-place rotation, furniture payloads, overwritten neighbors, snapshot Undo, repeated turns and union protection. It passed on the dev BDS on 2026-11-10. `build_rotate_mode` and `build_rotate_mode_exit` cover repeated mode taps, furniture, per-turn Undo and exits; in-game scenarios unverified. Manual BT38, BT46 and decoration rotation remain unverified.
